# プロフィールのファイル形式

`.skilltopo` は SkillTopo 用の圧縮バイナリ形式です。暗号化ではありません。

| オフセット | 内容 |
| --- | --- |
| 0–6 | 識別子 `53 4B 54 4F 50 4F 00`（`SKTOPO` + NUL） |
| 7 | バイナリ形式バージョン `01` |
| 8以降 | UTF-8 JSON を圧縮した単一の gzip ストリーム |

展開後は既存の `skilltopo-profile` バージョン1の JSON です。ユーザー名、全スキルの説明・関連情報・評価・メモなどを含みます。JSON の内容のバージョンと、バイナリ格納形式のバージョンは別に管理します。

読み込みは識別子から形式を判別します。JSON の UTF-8 BOM も許容します。未対応バージョン、gzip の破損、途中切断、不正なプロフィールは読み込めません。圧縮ファイルと展開後のデータの上限はそれぞれ8 MiBです。

デスクトップ版は保存先の拡張子が `.skilltopo` ならバイナリ、`.json` なら JSON を出力します（大文字小文字は区別しません）。新規・別名保存のダイアログは画面で選択した形式に合わせます。通常の保存は元の拡張子を維持し、外部で変更されたファイルは上書きせずエラーにします。

ブラウザプレビューも同じ形式を読み書きします。保存は選択した形式によるダウンロードです。
